Python code to calculate the occultation depth of an exoplanetary eclipse, showing the varying contributions from emitted and reflected light. The .py file requires some self-explanatory user inputs, defined in the top sections of the script. The code produces a plot showing the different contributions for a trio of albedos set by the user, when this quantity is unknown. Equilibium temperature is recalculated based on albedo, thus the shape of the total contribution changes with albedo. 

Dependencies are minimal, only requiring Python3, NumPy, pandas, and Matplotlib.
